# mac-notify

CLI 只在等待授权时会提示，很多"要用户动手"的时刻不会推送。此时调用：

```bash
"${CLAUDE_PLUGIN_ROOT}/scripts/notify.sh" "<要做的事>" "[标题]" "[点击打开的 URL]"
```

## 写法
- 一句话、<100 字、无 markdown，**以动作开头**：说清楚做什么、在哪做。
  - 好：`去浏览器点 ChatCut 授权，完成后我自动继续`
  - 好：`导出失败：磁盘满了，清理 ~/Desktop 后回复我`
  - 差：`任务更新` / `需要你的注意`
- 有可点链接（授权页、PR、文件）就传第三个参数，点通知直接打开。
- 标题按性质选：`需要你操作` / `需要你决定` / `任务完成` / `任务失败`。

## 规则
- 同一件事只推一次；推完继续等待/轮询，不要反复推。
- 推送后在对话里也写同样内容，方便用户回来看上下文。
- 若宿主有 `PushNotification` 工具（可推到手机），可同时调用；本脚本保证 Mac 桌面一定收到。

## 依赖
`brew install terminal-notifier`（缺失时自动退回 osascript，但点击无法跳转）。首次运行需在 系统设置 → 通知 里允许 terminal-notifier。
