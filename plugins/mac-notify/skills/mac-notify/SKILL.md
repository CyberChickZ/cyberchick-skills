# mac-notify

CLI 只在等待授权时会提示，很多"要用户动手"的时刻不会推送。此时调用：

```bash
"${CLAUDE_PLUGIN_ROOT}/scripts/notify.sh" [-l 1|2|3] [-n 次数] "<要做的事>" "[标题]" "[点击打开的 URL]"
```

## 三级强度（默认 1 级，次数默认 3）
| 级别 | 效果 | 用于 |
|---|---|---|
| `-l 1` | 系统通知横幅 + 提示音 | 长任务完成、非紧急的待确认 |
| `-l 2` | 1 级 + 屏幕边缘流光呼吸闪烁 + 顶部毛玻璃卡片 | 阻塞中：等授权/2FA/手动操作/决策 |
| `-l 3` | 2 级 + 屏幕晃动 + 白光闪烁 + 警示音（红色） | 时限紧迫（token/会话快过期）、高代价失败、1/2 级推过仍无回应 |

升级规则：同一件事先用合适级别推一次；>5 分钟无回应可升一级再推，最多到 3 级，之后不再推。覆盖层不拦截鼠标，播完自动消失。

## 写法
- 一句话、<100 字、无 markdown，**以动作开头**：说清楚做什么、在哪做。
  - 好：`去浏览器点 ChatCut 授权，完成后我自动继续`
  - 好：`导出失败：磁盘满了，清理 ~/Desktop 后回复我`
  - 差：`任务更新` / `需要你的注意`
- 有可点链接（授权页、PR、文件）就传第三个参数，点通知直接打开。
- 标题按性质选：`需要你操作` / `需要你决定` / `任务完成` / `任务失败`。

## 规则
- 同一件事只推一次；推完继续等待/轮询，不要反复推。
- 推送后在对话里也写同样内容，方便用户回来看上下文。
- 若宿主有 `PushNotification` 工具（可推到手机），可同时调用；本脚本保证 Mac 桌面一定收到。

## 依赖
需要 Xcode Command Line Tools（`swiftc`）。首次运行会在 `~/.cache/mac-notify/` 编译一个带 Claude 图标的小通知 app（图标从本机 `/Applications/Claude.app` 拷贝，没装则用默认图标），约 5 秒；系统会弹一次"允许 Claude 发送通知"，点允许。编译失败时退回 osascript。3 级晃动需要终端有"屏幕录制"权限，没有则只有流光和闪白。
